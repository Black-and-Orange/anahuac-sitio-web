# Logos de aliados de Biotecnología

Fuente: Excel Aliados y convenios de Biotecnología.xlsx proporcionado por el usuario el 2026-11-10. Logos extraídos sin modificar. INDRE y Elsevier usan los archivos separados entregados por el usuario. Silanes utiliza la copia raster de menor tamaño del mismo logo incluida en el libro.
